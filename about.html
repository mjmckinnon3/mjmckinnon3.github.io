About This Project

This website was created as part of an IT 3203 assignment to explain how server technology evolved over time. It covers the transition from centralized mainframes to virtualization and modern cloud computing.

The goal of this project is to clearly explain technical concepts in a simple and visual way, making it easier to understand how modern web infrastructure works.
