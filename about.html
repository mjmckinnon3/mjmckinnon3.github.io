About the Author

My name is Mary Jane McKinnon, and this website was created for IT 3203: Intro to Web Development. The project topic is the evolution of servers, including the movement from centralized systems to virtualization and cloud computing.

The purpose of this site is to demonstrate research organization, HTML structure, CSS styling, JavaScript functionality, responsive design, and mobile-friendly web development.

Design Choices

  • The site uses one external CSS file for consistent layout and styling.
  • The quiz uses one external JavaScript file for grading and feedback.
  • The layout uses CSS Grid, responsive images, flexible navigation, and media queries.
  • Tables are wrapped in horizontal scrolling containers so they remain usable on phones.
