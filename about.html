About This Project

This website was developed as part of the IT 3203 course to explore the evolution of server technology. The project focuses on how computing systems transitioned from centralized mainframes to distributed systems, virtualization, and modern cloud infrastructure.

The purpose of this project is to present technical concepts in a clear and structured way. By combining explanations, diagrams, and a self-assessment quiz, the site is designed to reinforce understanding of how server systems support modern applications.

Project Goals

  • Explain how server technology has changed over time
  • Highlight the importance of scalability and performance
  • Introduce key concepts such as virtualization and cloud computing
  • Provide an interactive quiz to reinforce learning

Technologies Used

  • HTML: Structured content and layout
  • CSS: Styling and responsive design
  • JavaScript: Quiz functionality and dynamic feedback

Why this topic matters

Understanding how servers evolved helps explain how modern websites, applications, and cloud services operate. These systems form the backbone of digital communication and data processing.

As demand for faster and more reliable systems continues to grow, server infrastructure will keep evolving to meet new challenges.
