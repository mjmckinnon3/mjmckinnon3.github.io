Key Concepts

This page defines the core terms used throughout the project.

ConceptDefinitionExample
ServerA computer or program that provides resources or services to clients.A web server hosting a website.
Client-server modelA network structure where client devices request services from servers.A browser requesting a page from a web server.
VirtualizationUsing software to create virtual versions of computing resources.Several VMs running on one physical host.
Cloud computingOn-demand computing resources delivered over the internet.Renting a virtual server from a cloud provider.
ScalabilityThe ability to grow capacity without major performance loss.Adding more servers during high traffic.
Load balancingDistributing traffic across multiple servers.A website sending requests to several backend servers.
RedundancyAdding backup components to reduce failure risk.Running duplicate servers in separate locations.
