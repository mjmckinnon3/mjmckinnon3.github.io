1. Server

A server is a system that stores, processes, or delivers resources to other systems on a network.

2. Client-server architecture

This model separates service providers from client devices that request and display information.

3. Virtualization

Virtualization lets multiple virtual systems run on one physical machine, improving efficiency and flexibility.

4. Cloud computing

Cloud computing delivers infrastructure and services over the internet instead of relying only on locally owned hardware.

5. Scalability

Scalability is the ability of a system to handle growth in users, traffic, or tasks without failing.

6. Reliability

Reliability means a server system continues functioning consistently with minimal downtime.

7. Serverless computing

Serverless computing hides server management from developers so they can focus more on application logic.
