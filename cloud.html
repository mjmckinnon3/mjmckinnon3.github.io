Student introduction

Name: Mary Jane Mckinnon

Course: IT 3203 - Intro to Web Development

School: Kennesaw State University

I am interested in technology and in the systems that make websites work behind the scenes. I selected server evolution as my project topic because servers are essential to nearly every digital experience, yet many users never think about how much infrastructure supports a single webpage request.

Purpose of the project

The goal of this project is to explain how servers evolved from centralized computing systems into modern cloud infrastructure. The site also demonstrates practical front-end skills such as semantic HTML, external CSS, multi-page navigation, responsive layout, JavaScript-based interactivity, and code documentation.

Project skills demonstrated

  • Multi-page website structure
  • Responsive navigation design
  • Semantic HTML elements
  • Single-file CSS styling
  • JavaScript form handling and dynamic feedback
